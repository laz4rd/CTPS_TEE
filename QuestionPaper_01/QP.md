# Section A

## Q1 (Compulsory)

### A) `CO-1` `BL-2` - [5 marks]
Comprehend the formula to calculate Body Mass Index (BMI) and write a C program to calculate a person's BMI. The program should prompt the user to enter weight in kilograms and height in meters. The program should then display the calculated BMI value.

$$BMI = \frac{weight}{height^2}$$

### B) `CO-2` `BL-3` - [5 marks]
Develop a program to help a toy vendor determine whether it results in a profit or a loss. Your program should accept the cost and the selling price as input and display whether the transaction is a Profit, a Loss, or neither. Consider all possible input scenarios.

### C) `CO-3` `BL-3` - [5 marks]
A temperature monitoring device continuously collects temperature readings in Celsius. Implement a program in C that uses a user-defined function `convertToFahrenheit()`, which accepts a Celsius value and returns its Fahrenheit equivalent. Display both the Celsius and Fahrenheit temperatures in `main()`.

### D) `CO-4` `BL-3` - [5 marks]
Build a C program that uses a structure to store Product details, including product code, Name, Quantity, and Price per unit. Read and display the details of one product.

## Q2

### A) `CO-3` `BL-3` - [10 marks]
Write a C program to input 10 elements into an array and sort all the elements in ascending order using Bubble Sort.

### B) `CO-1` `BL-2` - [10 marks]
What is decomposition and abstraction? Explain with an example.

A weather monitoring system records the temperature in degrees Celsius. Design a flowchart to classify temperatures into five categories:

| Category | Temperature |
|---|---|
| Very Hot | >= 40°C |
| Hot | 30°C to 39°C |
| Warm | 20°C to 29°C |
| Cool | 10°C to 19°C |
| Cold | < 10°C |

The flowchart should read the temperature, determine the appropriate category, and display the result.

- Append new student records (Roll Number, Name, and Marks).
- Search for a student record by Roll Number and display the corresponding details.

What is a string? Explain the string handling functions `strupr()`, `strrev()`, `strcat()`, and `strlen()` with an example.
